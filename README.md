# Site du Cabinet HANS-MOEVI AKUE

Site vitrine statique (une seule page `index.html` + dossier `img/`), conçu par SIP.

- Aperçu : GitHub Pages (Settings → Pages → branche `main`, dossier `/root`).
- Mise en ligne définitive : ajouter un fichier `CNAME` contenant le nom de domaine du cabinet, puis retirer la balise `<meta name="robots" content="noindex, nofollow">` de `index.html`.
